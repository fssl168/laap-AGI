# RSI 真实执行 + 参数优化：能否支撑论文观点 — 验证报告

> 验证日期：2026-08-15
> 验证对象：接入基于 RSI 的真实量化交易执行系统 + 参数优化后的证据
> 结论：**部分支撑，存在关键缺口与措辞风险。原始论文定位（受控模拟功能验证 + 探索性边界说明）可支撑；但若升级为"实证有效/真实执行已验证"则证据不足。**

---

## 1. 结论摘要

| 论文可能的声明强度 | 证据是否足够 | 判定 |
|---|---|---|
| A. 引擎具备 RSI 能力，受控模拟环境功能验证通过 | ✅ 足够 | 可写（可复现测试 370–453 passed） |
| B. 真实数据 OOS 作为**探索性边界说明**（如实报告负结果） | ✅ 足够 | 可写（负结果真实存在，恰好符合"探索性"定位） |
| C. 真实执行系统已运行、参数优化**实证了策略有效性/可盈利** | ❌ **不足** | 不可写（见 §4） |
| D. 参数搜索/进化管道 + 真实执行框架**已构建并通过真实数据 E2E** | ✅ 足够（措辞限定） | 可写（sandbox 真实 kline E2E 通过，但非持续运行） |

**一句话**：证据支撑"能力达成、管道接通、边界诚实"这三个声明；**不支撑"实证通过 / 可盈利 / 真实运行"** 这三个声明。

## 2. 论文观点定位（来自项目文档的不变量）

来源：`docs/phase2-multi-factor-strategy-plan.md` §1.1、`docs/true-rsi-feasibility.md`。

- 论文《**Aris认知引擎RSI能力实证评估**》定位 = **受控模拟环境功能验证，非实证评测**
- 真实数据 OOS 回测为**探索性边界说明**，如实报告负结果，**不宣称"实证通过"**
- 措辞须匹配证据强度（用户既定原则）

> ⚠️ **术语冲突（关键）**：论文标题中 "RSI" = **Recursive Self-Improvement（递归自我改进）**（`laap/agi/rsi_engine.py`，参数自调优引擎）；而近期"真实量化交易执行系统 + 参数优化"中的 "RSI" = **Relative Strength Index（相对强弱指标）**（`scripts/backtest_multi_symbol.py` 的 Wilder RSI 趋势策略）。两者同名不同义——验证时必须区分"引擎的自改进能力"与"RSI 指标的策略有效性"。

## 4. 逐条核验：证据 vs 论文观点

### 观点 A（受控模拟功能验证）— 支撑成立
引擎能力（RSI 指标计算 / 信号生成 / 参数自调优 / M4 受限递归 / 记忆闭环 / 交易自我）在受控环境有可复现测试（370→453 passed 基线），与"功能验证"定位一致。**此为论文最稳的支柱。**

### 观点 B（探索性边界说明）— 支撑成立（前提：如实报告负结果）
§3.1 的负结果（超额收益为负、显著性不足、walkforward FAIL、AB phantom PnL 为负）**恰好是"探索性边界说明"应当呈现的内容**。只要论文按现有原则如实写，这些数据不会削弱定位，反而是"边界刻画"的证据。

### 观点 C（实证策略有效 / 真实执行已验证）— 证据不足，禁止宣称
从数据看，若把 §3.1 解读为"实证支持"，会面临以下硬伤：

1. **平均超额收益为负**：56 标的平均跑输买入持有 1.4%——策略整体无增量价值。
2. **显著性缺失**：仅 1–2/56 达 \|\|z\|\|≥1.96，低于随机期望的 5%（约 2.8 个）。**在多重检验下出现高夏普标的恰恰是偶然，不是效应**。
3. **Walkforward 官方判定 FAIL**（pass_rate 6.7% vs 阈值 40%）：稳健性检验是反证。
4. **"真实执行"尚无真实业绩**：DB 只有 demo seed；开关已启用（2026-08-15）、调度器已接交易日历，但需 ≥1 个月真实交易日积累才产生业绩。论文若写"接入真实执行系统"须限定为"框架已构建并通过真实数据 E2E"+"已配置自动运行"，而非"系统已真实运行产生收益"。
5. **小样本失真**：42/56 标的仅 64 天、OOS 14 天；33/56 仅 1 笔 OOS 交易。单笔交易的"日收益方差≈0"会把夏普顶到 18.29 这类天文数字，统计上无意义。

### 观点 D（管道已构建 + 真实数据 E2E）— 支撑成立（措辞限定）
参数搜索 → 进化 → 治理链 → `apply_params_to_code` 落回 → `run_daily_cycle` 执行，sandbox 内真实 kline E2E 通过。**论文可声明的是"管道打通 + 单次真实数据 E2E 验证"，不可声明"持续运行验证"。**

## 5. 方法学缺陷（审稿人会追问，务必先自首）

| # | 缺陷 | 影响 |
|---|---|---|
| M1 | **多重检验/选择偏差**：每标的在训练集网格选最优参数，再报 OOS；56 标的 × 多参数组合下，必然有少数"看起来不错"的 OOS | 高夏普标的不可作为"有效"证据 |
| M2 | **小样本夏普通胀**：14 天 OOS + 1 笔交易 → 夏普失真 | 平均夏普 3.44 无统计含义 |
| M3 | **无成本/滑点/T+1/涨跌停建模**：收盘价同 bar 成交，理想化 | 正收益被高估 |
| M4 | **策略极简**：RSI>阈值持有、≤阈值清仓，在短窗口约等于趋势/动量近似 | 结论外推性弱 |
| M5 | **"优化→执行"闭环只在测试**：参数优化在历史 K 线回测；执行系统未持续运行 → 两者是"分别验证"而非"端到端验证" | 论点 C/D 的衔接断层 |
| M6 | **样本时间过短**：64 天 K 线（2026-05-18~08-14）跨单一行情段，无跨周期（牛/熊/震荡）稳健性 | 无法证明跨环境有效 |

## 6. 推荐措辞与后续行动

### 论文可写（证据支撑的声明）
1. "Aris 引擎具备 RSI（递归自我改进）能力，在受控模拟环境完成功能验证（测试基线 xxx passed / 0 failed）。"
2. "已构建基于 RSI（相对强弱指标）的真实 K 线参数搜索与进化管道，接入 paper-trading 执行框架并通过真实数据端到端验证。"
3. "56 标的多时段样本外探索：正收益标的占比约 66%，但平均超额收益为负、显著标的仅 1–2 个、walkforward 通过率 6.7%——**策略尚未证实稳定可盈利，参数鲁棒性不足**。该负结果构成系统的边界刻画。"

### 论文禁写（证据不足以支撑的声明）
- ❌ "真实执行系统验证了策略有效性 / 实证通过 / 可盈利"
- ❌ "参数优化显著提升了样本外表现"（无显著性支撑）
- ❌ "系统已在真实行情下持续运行并产生收益"（无运行记录）

### 若要升级论点 C（可选，成本高）
1. **扩大样本**：全 A 股或 ≥200 只标的，每标的 ≥500 天，OOS ≥60 天，控制多重检验（Bonferroni/FDR）。
2. **加交易成本**：佣金+印花税+滑点+T+1 锁仓后再算超额。
3. **跨周期验证**：牛/熊/震荡分段分别报告。
4. **真实执行留痕**：确保 `LAAP_QUANT_DAILY=1`（2026-08-15 已启用）持续运行 ≥1 个月，产生真实 paper 交易序列，用真实成交业绩（而非回测）作为论点 C 证据。
5. **诚实负结果作为贡献**：若不愿投入上述成本，把"构建了完整闭环、但实证上策略不显著"作为论文的工程/系统贡献，是最省力且无审稿风险的写法。
