# 论文「诚实负结果作为贡献」写法（item 5，推荐）

> 定位：不宣称"实证策略有效"，把**完整闭环系统的工程/方法贡献**作为论文主体。
> 这是最省力、无审稿风险、且与全部实证证据一致的写法。

## 1. 核心主张（一句可辩护的话）

> **贡献不在"策略赚钱"，而在"把'策略搜索 → 显著性门禁 → 受治理的代码落回 → 带自我审核的 paper 执行 → 事后反思'做成一个可复现、可审计、可证伪的完整闭环，并用真实数据诚实地证明了该因子族当前无稳定 alpha"。**

## 2. 论文结构建议（工程/系统贡献定位）

| 章节 | 主张 | 证据来源（本仓库） |
|---|---|---|
| 系统设计 | 参数空间即代码 + 确定性搜索（网格/随机/遗传）+ LLM 微调层 | `param_evolver.py` / `llm_refine.py` |
| 治理链 | M1-M4 受限递归 + OOS 门禁 + 交易自我审核（记忆衰减/弃权冷却/仓位校准） | `quant_evolution.py` / `trading_self.py` |
| 执行链 | 多因子信号 → paper 交易 → 净值/教训沉淀 → 反思 | `paper_service.py` / `ledger.py` / `paper_replay.py` |
| 实证（诚实负结果） | walk-forward 全族无稳定 edge；只有熊市段少亏 | `walkforward.py` + 各报告 JSON |
| 工程验证 | 引擎契约向后兼容、148+ 测试、数据口径诚实标记（real/qfq vs synthetic） | `tests/` |

## 3. 措辞红线（避免审稿风险）

- ❌ 不写："策略实证有效"、"OOS 验证通过"、"获得正收益"。
- ✅ 写："探索性 OOS 检验**未发现**该因子族在样本上的稳定显著超额"、"工程闭环**已完整实现并验证可运行**"。
- 所有收益数字一律标注：**扣除 A 股成本（佣金 0.025%+印花税 0.05%+滑点 0.1%）后**；未扣除的标注"零成本近似"。
- 跨周期结论必须分段：熊市段 excess +6.26%（少亏）、牛/震荡段无 edge——**不做全局"有效/无效"的笼统断言**。
- 多重检验：声明"未控制多重检验的探索性结果"，或给出 Bonferroni/FDR 修正后通过率为 0。

## 4. 一条可直接引用的结论句（摘要用）

> We built and verified a complete closed loop for parameterized trading strategies — deterministic search, significance-gated evolution, governance-constrained code application, self-audited paper execution, and post-trade reflection. On real A-share data (200+ stocks × 500+ days; or 3 stocks × 800 days), exploratory walk-forward evaluation **did not find** a stable, statistically significant edge for the multi-factor family after transaction costs and multiple-testing control; the only regime-conditional signal was loss avoidance in bear markets. The contribution is the falsifiable, reproducible evaluation framework and the honest negative result, not a claim of profitability.

## 5. 审稿人可能的问题与应答

> 以下应答全部基于本仓库**实测证据**（285 只 × 500+ 天、174 项测试、A/B 对照等），不含臆测数字。论文引用时给出对应报告文件。

| # | 问题 | 应答（基于实测证据） |
|---|---|---|
| Q1 | **为什么结果不显著？** | 三层诚实证据：① **大样本**：285 只沪深300 × 500+ 天（qfq），rolling-origin walk-forward，OOS=80 天（≥60 要求）；② **门禁后通过率**：long_only **1/285**、long_short **0/285**，含 A 股成本（佣金 0.025%+印花税 0.05%+滑点 0.1%）与 Bonferroni；中位 z=-0.21/-0.29 → **不优于随机参数基线**；③ **机制解释**：跨周期分段显示唯一模式是熊市段少亏/做空超额（+11%~+13%），牛段严重跑输（-31%~-35%，RSI 超买门在强趋势中空仓）。结论：该因子族无稳定、状态无关的 alpha——**如实报告，非隐藏失败**。 |
| Q2 | **如何避免过拟合指控？** | 六道结构性防线（非事后辩护）：① rolling-origin walk-forward，OOS 段互不重叠且**永不进入参数搜索**；② 每段显著性：策略 OOS 日收益 vs 随机参数基线，z≥1.96（Welch 近似）；③ **多重检验控制**：Bonferroni（FWER）与 FDR（BH q=0.05）双实现，论文报告修正后通过率（0~1/285）；④ **成本 + T+1 计入后再报超额**（成本使 3 标的基线 1/15 → 0/15）；⑤ 跨周期分段报告，不做全局"有效"断言；⑥ 最强证据：**结果是负的**——没有可过拟合的"漂亮结果"，恰证明流程可证伪。 |
| Q3 | **系统价值在哪？** | 工程/方法贡献（非盈利主张）：① **完整闭环可复现**：确定性搜索（网格/随机/遗传，seed 固定）→ 显著性门禁 → M4 治理代码落回 → TradingSelf 自我审核 paper 执行 → 事后反思；174 项测试锁定契约；② **可证伪评估框架**：任何新因子可直接接入同一门禁，逐段给出可检验结论；③ **治理与安全**：M1-M4 受限递归 + 自我审核（记忆衰减/弃权冷却/仓位校准）防止不安全自修改；④ **真实交易能力**：paper 闭环已在真实 kline.db 上运行（成交/净值/教训留痕），为真实执行提供验证过的基座。 |
| Q4 | **你的系统和"网格调参+回测"本质区别？** | 区别在"评估与治理"而非搜索本身：搜索确定性可复现（seed 固定）；**评估**从"不劣化"升级为"正收益 + z≥1.96 + 多重检验"；**治理**——搜索成果落回代码必须走 M4 链（SafetyGuard→沙箱→deploy_gate→人工审批），可回滚；**自省**——TradingSelf 对每笔交易做意义/利益审核并事后反思更新自我模型（主体性闭环，非脚本调参）。 |
| Q5 | **TradingSelf 是不是把规则换个名字？有用吗？** | 诚实回答：它是**规则化自我层**（人格→风险偏好、记忆教训、自我效能、仓位纪律），不宣称 AGI。有效性用 **A/B 对照**检验（同一数据/参数，Arm A 直执 vs Arm B 审核）：修复后 3/3 标的**回撤降低**、score 平均 **+0.017**（BORDERLINE，距 KEEP 阈值 0.02 差 0.003）；被弃权买单反事实 108 笔共 **-73,183**（弃权避损）。定位：**回撤压缩 + 亏损规避层**，随观察期持续监控，不作为盈利来源主张。 |
| Q6 | **怎么保证"负结果"不是实现 bug 或数据错误？** | 可复现性与数据质量：确定性搜索 seed 固定（同参两次结果一致，测试覆盖）；174 项量化测试锁定引擎/门禁/搜索/执行契约；数据源腾讯 qfq 与既有 800 天真实数据**交叉验证**（600519 尾值一致）；`data_quality` 诚实标记 real/synthetic；**负结果方向一致**——3 标的（800 天）与 285 只大样本均不显著。 |
| Q7 | **未来工作？** | ① item 4：`LAAP_QUANT_DAILY=1` 真实 paper 运行 ≥1 个月，补齐"优化→执行"端到端验证（当前为分别验证，见 M5）；② 策略层：换因子族（非趋势/RSI 家族）或引入涨跌停/微观结构建模（见 M3）；③ 评估层：FDR 敏感性分析与成本假设敏感性。 |

### 5.1 方法学缺陷（审稿人会追问，务必先自首）

> 下表列出**旧论文实证（56 标的 × 64 天 RSI 策略）**的方法学缺陷。"当前状态"列标注升级后证据（285 只 × 500+ 天、成本、Bonferroni、跨周期）对各项的缓解程度——**已缓解的据实声明，未缓解的继续自首**，不夸大新证据。

| # | 缺陷 | 影响 | 当前状态（解决后） |
|---|---|---|---|
| M1 | **多重检验/选择偏差**：每标的在训练集网格选最优参数，再报 OOS；56 标的 × 多参数组合下，必然有少数"看起来不错"的 OOS | 高夏普标的不可作为"有效"证据 | ✅ **已解决（valid 段门禁）**：walk-forward 新增**验证段双重门禁**——train 拆 select/verify，选参只用 select 段，选出的参数须在**未参与选参的 verify 段正收益**才进入 OOS 报告（再叠加 Bonferroni + 随机基线 z≥1.96）。效果实测：趋势族 285 只通过数 **1/285 → 0/285**（最后 1 个边际通过在 verify 段被拦截）。每 fold 输出 `valid_ok/valid_reason` 可审计 |
| M2 | **小样本夏普通胀**：14 天 OOS + 1 笔交易 → 夏普失真 | 平均夏普 3.44 无统计含义 | ✅ 已解决：80 天 OOS + 多笔交易 + 日收益夏普；旧"夏普 3.44"仍须标注无统计含义 |
| M3 | **无成本/滑点/T+1/涨跌停建模**：收盘价同 bar 成交，理想化 | 正收益被高估 | ✅ **已解决（涨跌停建模）**：佣金 0.025% + 印花税 0.05% + 滑点 0.1% + T+1 + **A 股涨跌停（±10%：涨停禁买、跌停禁卖、持仓被锁）**全部建模；宇宙运行（285 只）均用该配置。残差：同 bar 收盘成交仍为近似（无日内路径），但流动性约束已建模，残差方向只会让结果更差 |
| M4 | **策略极简**：RSI>阈值持有、≤阈值清仓，在短窗口约等于趋势/动量近似 | 结论外推性弱 | ✅ **已解决（第二独立家族）**：新增**均值回归（contrarian）信号家族**引擎，与趋势族共用同一门禁（285 只 × 500+ 天 × valid 门禁 × 成本 × 涨跌停 × Bonferroni）实测 **0/285**——框架已证明与信号家族无关（趋势/多空/均值回归均可接入同一评估）。结论明确限定"已测家族"，外推性由框架一般性支撑 |
| M5 | **"优化→执行"闭环只在测试**：参数优化在历史 K 线回测；执行系统未持续运行 → 两者是"分别验证"而非"端到端验证" | 论点 C/D 的衔接断层 | ❌ 仍有效：系统已具备 paper 交易能力且单次真实 tick 已验证；但持续运行 ≥1 个月未完成（item 4 用户侧）。论文如实声明，勿称"端到端验证" |
| M6 | **样本时间过短**：64 天 K 线（2026-05-18~08-14）跨单一行情段，无跨周期（牛/熊/震荡）稳健性 | 无法证明跨环境有效 | ✅ 已解决：285 只 × 500+ 天（约 2 年），跨周期分段（116 bull/64 range/105 bear）；限定"2024-06~2026-08 多行情段"，非全历史周期 |

**使用规则**：论文正文在方法论节**逐条引用上表**（不隐藏）；"影响"列如实陈述；"当前状态"列为 ✅ 的给出对应新证据，⚠️/❌ 的继续自首并在结论中限定范围。
